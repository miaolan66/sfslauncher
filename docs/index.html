实例
01

每个实例，一套自己的配置

同一台机器上装了几份 SFS？给每份建一个实例，路径、模组、存档各管各的，互不覆盖。自动检测 Steam 安装，也支持手动指定。首页顺手记着挑战进度和游玩时长。

  • 添加实例、切换实例，启动前先做一次完整性预检查
  • 游戏崩溃时弹窗提示，不会无声退出
02

装了哪些模组，一眼看得见

每个实例的模组单独列出，按类型分胶囊筛选。支持导入扩展包、导出模组清单，也盯着版本有没有更新。

  • 长列表分片渲染，几百个模组也不卡
  • 已装列表支持虚拟滚动
03

116 个模组，选中就进下载队列

商店里按分类过滤，挑中的直接落到待安装列表，装完再并入实例。下载失败会重试，队列进度写在下载队列页里。

  • 按分类过滤之后再挑
  • 下载到待安装列表，不直接改进游戏目录
04

蓝图和存档，点开文件夹就在

蓝图页直接扫游戏目录，按文件夹展开缩略图，不用一层层翻资源管理器。存档支持一键备份与还原，误删也有退路。

  • 蓝图按文件夹展开，不用一层层翻资源管理器
  • 存档一键备份与还原
05

毛玻璃不是一个开关

koffi 直调 Win32 / DWM：Win10 走原生模糊，Win11 走云母和亚克力。探测不到就回退实色，不会给你留一块半透明的糊字。

  • 五档材质：关闭、Aero、亚克力、云母、琉璃
  • 琉璃另配四个滑块：内容通透度、壁纸遮罩、壁纸模糊、泛光

下载 0.88.0

Windows 10 / 11 x64。需要先装好 Spaceflight Simulator，启动器不含游戏本体。

安装包 NSIS · 80.5 MB · 写入开始菜单与卸载项 下载安装包
便携版 单文件 · 80.2 MB · 解压即用，不写注册表 下载便携版

全部版本都在 GitHub Releases，源码在 GitHub 仓库。汉化由内置的 SFSChineseInjector 注入器完成。

装好之后，三步开始

  1. 1

    添加游戏实例

    首页点「添加游戏实例」，选到 SFS 的 exe；Steam 版直接点「自动检测 Steam」。

  2. 2

    按需装模组

    「模组商店」里挑中的会进下载队列，装完回「模组」页就能看到。

  3. 3

    点开始游戏

    回首页点「开始游戏」。有多份 SFS，就在「我的游戏」里切换实例。
